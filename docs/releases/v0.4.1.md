# Beam Weaver v0.4.1

This release makes the generate → train → simulate → compare workflow easier to
follow, especially on the first run. It changes explanations, progress output,
and automatic run-directory names. The photon interaction samplers, 13-head
factorization, cross-entropy objective, and shared free-flight and charged
particle transport are unchanged.

## Console guidance

- Each menu operation explains its inputs, computation and saved outputs.
- Generation names the **fixed incident photon energies** sampled by Beam
  Spinner. It lists all 64 logarithmically spaced training values from 1 keV
  to 10 MeV, the five extra points near pair threshold (1.023, 1.030, 1.050,
  1.075, 1.100 MeV), 63 validation midpoints and the nine test values (0.010,
  0.020, 0.050, 0.100, 0.5, 1, 2, 5, 10 MeV). It shows progress within each
  split and explains 69 × 9 + 21 = 642 training, 63 × 9 + 16 = 583 validation
  and 9 × 9 + 3 = 84 test **reference sampling sets**. One set is a batch of
  Monte Carlo outcomes at one fixed energy for one sampled quantity, with a
  fixed shell for photoelectric outcomes. They are distinct from histogram
  bins for angles or energy fractions.
- Training explains that 13 heads are fitted separately, with up to 400 epochs
  for grouped empirical distributions and 20 for the four pair-direction
  heads fitted to individual events. Validation cross-entropy chooses the best
  checkpoint and supports early stopping. Single-head training in a fresh run
  leaves the other heads untrained; resume a matching complete policy to
  replace one head.
- Comparison calls its input **primary photon histories per selected energy
  per method**. The default 2,000 is applied separately to MC1, MC2 and Beam
  Weaver at each of the four default comparison energies.
- Automatic output names now follow `runs/<command>-YYYYMMDD-vN`, with the
  next unused `vN` for that operation on that UTC date. The `vN` suffix is a
  daily run count, not the Beam Weaver software version. Explicit output paths
  and training resume paths remain explicit. Command audit records within a
  run use `command-YYYYMMDD-vN.json`; dataset and checkpoint names are unchanged.

## Documentation and existing results since v0.4.0

The README now documents the factorized interaction law, masked cross-entropy
training and the water-data provenance in more detail. The architecture and
material-table notes were revised, and AI-assisted work is disclosed. The
existing five-energy results gallery was reorganized: available source data
and saved-label provenance are described more clearly, and panels without
saved measurements are omitted. **The gallery is not a new simulation run or
an independent validation of v0.4.1.** No pretrained checkpoint is bundled.

## Scope and citation

Beam Weaver is a research prototype for photon transport in water. Photon
free-flight sampling and approximate electron/positron transport remain
conventional Monte Carlo components. The supplied historical timings do not
establish a speed advantage. Passing software regression checks does not
establish physical or clinical validation.

The [v0.4.0 Zenodo DOI](https://doi.org/10.5281/zenodo.22739031) refers to
the archived v0.4.0 code, not this version. The
[all-versions DOI](https://doi.org/10.5281/zenodo.18994134) identifies the
project archive. Add a v0.4.1 version DOI only after that archive exists.

For a full checkout including the supplied water CSV tables, clone this
repository at `v0.4.1` once tagged, then run:

```bash
python -m pip install -e '.[learn]'
python -m beamweaver
```

Python 3.10 or later is required. Training and learned transport require
PyTorch and a trained checkpoint. The water tables must be supplied separately
if installing a distribution that does not contain the repository-root CSVs.
