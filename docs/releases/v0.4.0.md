# Beam Weaver v0.4.0

Beam Weaver now learns local stochastic photon-transport kernels directly from Monte Carlo collision samples. Thirteen separate neural heads supply collision variables during recursive showers, with explicit conservation laws and shared reference transport for photon free flight and charged particles.

## Changes since the 0.1 releases

- Replace the SAC-era application with the modular `beamweaver` package and a generate → train → simulate → compare workflow.
- Provide a six-option interactive menu and matching commands, including **“Train all heads or one selected head”**, resumable training and audited learned showers.
- Consolidate duplicate constants while preserving numerical behavior, category ordering, random streams and caller overrides; separately harmonize the rest energy to `mec2 = 0.51099895069` MeV and derive the pair threshold from it.
- Clarify Compton energy-ratio sampling versus complete-event reconstruction and repair obsolete lepton-transport call arguments that blocked learned showers.
- Include water tables, installation instructions, regression checks, source provenance and method limitations.
- Restore the project’s [all-versions Zenodo DOI](https://doi.org/10.5281/zenodo.18994134) and update current citation metadata. Earlier version-specific DOIs remain historical records.
- Document the method in the README and add a [results gallery](https://github.com/PedroTelesFCUP/Beam_weaver/tree/main/results) for **0.1, 1, 2, 5 and 10 MeV**, with matching figure categories and the five original 5 MeV figures.

## Results provenance

The gallery reports results obtained with **Beam Weaver v0.4.0**: 50,000 primary photons per simulation with MC1, MC2 and Beam Weaver. They were saved under older `0.2.9` labels. The source metadata retain `0.2.9e` and the `pretrain_v029e` checkpoint path as saved labels for traceability; these labels do not identify the version used to obtain the results. Recorded timings are campaign measurements, not portable hardware benchmarks.

## Installation

For a complete runnable checkout with the six water CSV tables, clone this repository at `v0.4.0` or download GitHub’s **Source code (zip)** / **Source code (tar.gz)** archive, extract it and run:

```bash
python -m pip install -e '.[learn]'
python -m beamweaver
```

Python 3.10 or later is required. The wheel and Python source distribution are also attached; water tables are provided in the repository/GitHub source archive and must be supplied separately when installing those distributions. Training or learned transport requires PyTorch and a trained policy; no pretrained checkpoint is bundled.

## Validation and history

This release is published only after the **Python checks** workflow succeeds for its exact commit on `main`. The check suite covers constants, ordering and random-stream regressions, Compton kinematics, pair thresholds and energy accounting, CLI behavior and learned transport. Optional original-source comparisons are reported as skipped when the external original file is unavailable. Passing these checks establishes the covered code behavior, not independent validation of the approximate transport model.

The preceding repository remains at [`archive/sac-before-0.4.0`](https://github.com/PedroTelesFCUP/Beam_weaver/tree/archive/sac-before-0.4.0); tags `v0.1.0` and `v0.1.0.1` and their releases are preserved.
